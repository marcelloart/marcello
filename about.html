Tentang MarcelloArt

Studio game indie yang membangun game, mendokumentasikan proses pengembangan, dan membuka ruang feedback untuk pemain.

Terakhir diperbarui: 20 September 2026

Apa itu MarcelloArt?

MarcelloArt adalah studio game indie yang mengembangkan dan menerbitkan proyek game sendiri. Website ini menjadi pusat informasi resmi untuk game, update pengembangan, artikel panduan, changelog, status testing, dan kanal dukungan.

Proyek utama saat ini

Fokus utama saat ini adalah Coin Rush 3D, game runner 3D Android dengan progres level, checkpoint challenge, power-up, misi, hadiah harian, outfit, dan fitur yang terus disempurnakan melalui proses pengujian.

Mengapa ada blog?

Blog MarcelloArt dibuat untuk mendokumentasikan perkembangan secara terbuka dan membantu pemain memahami mekanik game. Artikel mencakup panduan pemula, power-up, checkpoint, performa, pengujian, serta perubahan penting pada build baru.

Prinsip konten

Artikel diupayakan orisinal, relevan dengan produk dan pengalaman pengembangan MarcelloArt, serta diperbarui ketika perubahan game membuat informasi lama tidak lagi akurat. Konten tidak dibuat untuk meniru situs lain atau mengisi halaman tanpa nilai bagi pembaca.

Feedback pemain

Masukan selama pengembangan sangat berguna untuk menemukan bug, masalah kompatibilitas, dan bagian gameplay yang perlu diperbaiki. Pemain dapat mengirim laporan melalui Masukan & Dukungan.
