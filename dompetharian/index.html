OTOMATIS DI HP

Catatan & salinan lokal

Catatan, draf, dan foto disimpan di ruang privat aplikasi. Hingga tujuh versi catatan tersimpan dan foto dibuat sebagai salinan lokal terenkripsi, tanpa mengirimnya ke cloud.

Catatan dan salinan lokal ikut hilang jika aplikasi dihapus, data aplikasi dibersihkan, atau HP hilang. Salinan ini hanya bisa dibuka pada instalasi yang sama.

EKSPOR MANUAL

Backup file pilihanmu

Jika ingin menyimpan di luar aplikasi, buat backup terenkripsi lewat Backup & data. Kamu menentukan sendiri lokasi dan kata sandinya. Tersedia juga ekspor CSV dan JSON.

Pemulihan menampilkan pratinjau dan memerlukan konfirmasi. Backup bukan sinkronisasi gabung data antarperangkat; draf tetap di HP asal.

Cara penyimpanan bekerja →

Mulai versi 0.4.6, login dan cadangan otomatis Google Drive dihapus. Salinan otomatis dapat tertunda oleh pembatasan Android atau ruang penyimpanan; catatan utama tetap disimpan saat kamu menekan OK atau Simpan.

SEBELUM MULAI

Pertanyaan yang sering muncul.

Apakah DompetHarian menyimpan uang sungguhan?

DompetHarian hanya mencatat transaksi secara manual. Aplikasi tidak menerima dana, memindahkan uang, menghubungkan rekening bank, atau memproses pembayaran.

Apakah wajib login Google?

Tidak. Versi 0.4.6 langsung dipakai tanpa akun. Login Google dan cadangan otomatis Drive sudah dihapus.

Apakah mengetik langsung menambah transaksi?

Belum. Mengetik membuat draf lokal. Periksa pratinjau dan tekan OK atau Enter untuk menyimpan transaksi.

Bagaimana jika HP berganti atau aplikasi terhapus?

Pulihkan dari file backup yang sebelumnya sudah kamu ekspor dan simpan di luar aplikasi. Backup terenkripsi memerlukan kata sandinya. Catatan, salinan otomatis, dan draf di ruang aplikasi ikut terhapus saat uninstall; aplikasi tidak dapat mengambilnya kembali tanpa file backup terpisah.

Apakah foto dan catatan dikirim ke pengiklan?

Aplikasi tidak mengirim nominal, keterangan, kategori, foto, atau isi backup sebagai parameter iklan. SDK Google Mobile Ads dapat memproses data perangkat dan interaksi. Baca penjelasan periklanan untuk rinciannya.

Bagaimana cara mencoba aplikasi atau melaporkan masalah?

Aplikasi masih dalam tahap pengujian. Hubungi marcelloartis@gmail.com untuk menanyakan ketersediaan versi uji. Saat melaporkan masalah, sertakan versi aplikasi, perangkat, dan langkah kejadian; samarkan informasi keuangan pribadi.
